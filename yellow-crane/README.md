# 武汉黄鹤楼微缩立体模型（Yellow Crane Tower diorama）

第三座沙盘子项目，与故宫、西湖同一套管线（`west-lake/` 的脚本派生）：Blender 5.x 过程化生成，Cycles 渲染成图，
并以 `--export-glb` 导出 Three.js 网页版（`dioramas/yellow-crane/`）。

内容：蛇山台地上的黄鹤楼（三层石台、五层平座朱栏、每面三翘角的黄色琉璃瓦飞檐、攒尖宝顶）、
公园的牌坊、碑廊、亭台、白云阁、鹅池与山径，斜贯沙盘的长江与江滩滨江路，武汉长江大桥（见下），
对岸龟山、电视塔与晴川阁，两岸粉墙黛瓦的老城，江上货驳、游轮与小船（带尾迹），
Poly Haven 扫描树木实例化的松林与垂柳，日落纯天空 HDRI 的金色低角度阳光与贴水薄雾。

## 目录

| 路径 | 内容 |
|---|---|
| `build_yellow_crane.py` | 唯一的脚本：地形、建模、材质、灯光、相机、雾、渲染、网页导出 |
| `../assets/textures_cc0/`、`../assets/polyhaven/` | CC0 贴图、树木模型与 HDRI（后者不入库，见其 README） |
| `output/yellow_crane/yellow_crane.png` | 正式成图（2048×1792，64 spp） |
| `output/yellow_crane/yellow_crane.blend` | 工程文件（不入库） |

## 运行

```bash
npm run blender:crane            # 正式渲染（约 20 分钟）
npm run blender:crane:preview    # 快速预览（40%，16 spp）
npm run blender:crane:web        # 导出网页版 glb + scene.json
```

直接调用脚本的参数：`--pct`、`--samples`、`--out`、`--save`、`--nomist`、`--nohdri`、`--sunonly`、
`--border x0 y0 x1 y1`、`--export-glb <dir>`、`--foam`（船尾迹的浓度，默认 0.8）。
坐标：1 个 Blender 单位 ≈ 12 米，y 轴正方向为北，江面 z = 0。

## 黄鹤楼脚下的石矶和台地

楼的基座立在 `ground(楼心)` = 12.7 的高度，而原来周围的台地只有 9.6，西北角下面干脆是江面：石台整个悬空，
牌坊、碑廊、亭子不是悬空就是埋在石台里。现在把这座山补实成一座临江的石矶（黄鹄矶）：

- **山体**（`terrain_geo()`）：山顶是放石台的平地，四周是很陡的岩壁，崖脚一圈乱石滩伸进水里；
  东面接蛇山的地方比广场高，削成坡。陡面用岩石材质 `HillRock`（Rock051 贴图，朝上的面生苔）。
- **砌体**（`tower_hill()`）：山顶广场四周的条石挡墙和栏杆；南面两层石砌台地，三层之字形台阶从广场下到前场；
  台地上是牌坊和两座碑廊，广场四角各一座亭子，前场还有一道牌坊。山径从前场出发，穿过大桥引桥的拱洞进老城。
- **树**：崖脚一圈的树、岩缝里的灌木和小松、东坡的松林、台地上的点景树，都由 `tower_hill()` 自己摆；
  白云阁周围原来秃着的一圈也补上了。

只改地形网格的高度，`terrain()` / `ground()` 一个字不动：种树、建房的判断都用它们，判断不变，随机数的消耗就不变，
别处的树和房子不会跟着变。摆放高度一律用 `surface()`。原来摆在这一带的建筑在旧位置照原样走一遍（只登记避让范围，
几何丢掉），新的摆完以后把它们自己登记的避让范围删掉。

## 现代城区

`city()` 铺街区，`tower_block()` 盖高楼。原来的楼是白底横条的方盒子，立在一块空铺地上，同一街区里的楼还会互相穿插。

- **高楼三种做法**：玻璃幕墙写字楼（楼板线、竖梃，高的顶上有收进的机房层和天线）、住宅板楼（窗带被窗间墙分成一格格的窗，
  朝南挂阳台，屋顶有水箱）、竖向窗带的塔楼（顶上两层收进）。多数带裙楼，屋顶有女儿墙和设备间。
- **街区**：除了高楼，还有几栋沿街的三到七层的多层楼、一两块带树的绿地、沿地块四边的行道树，街上有车和黄色中线。
  坡地上的街区下面垫石砌护坡（原来是一块悬空的板）。
- 重叠的高楼挪到旁边的空处，挪不开就不建。

高楼的位置、大小、层数仍按原来的顺序抽全局随机数，其余的变化都用按街区定种子的随机数，别处的树和房子不变。

## 老城和补出来的新街区

- **民居**（`_house()`）：一排联排的老房子，硬山瓦顶，两端和几户之间立三级叠落的马头墙，正面一条木门板，背面和楼上开窗；
  墙面有粉墙、青砖、红砖三种。原来每栋都是一样的白盒子加四坡顶。
- **老城街区**（`town_block()`）：沿街两排民居，院里一到三座厢房把前后两排连成几进院子，院里种树，街区两头是院墙和门楼。
- **补新街区**（`grow_quarters()`）：原来两岸大片平地是空草地。现在从已有的街区出发往外补：
  老城旁边长出老城街区，现代城区旁边长出多层住宅小区（`xiaoqu_block()`：三排朝南的板楼，排间绿地，偶尔换成一块街心公园）。
  第一轮贴着已有街区按原来的间距往四个方向长；第二轮见缝插针，补网格对不上的空地。
  只落在平坦、离江和岛缘够远、不压已有建筑、大桥、石矶和山径的地方。

新街区不登记 `keep()`（那会改动后面种树的随机数），范围记在 `NEW_ZONES` 里由 `no_plant()` 挡树；压在下面的已有的树拿掉
（`PLANT_REG` 记着每棵树）。老城原有街区的随机数抽取顺序没变，其余变化用按街区、按房子定种子的随机数。

## 长江大桥和江水

`yangtze_bridge()` 照 1957 年的武汉长江大桥来做：

- **正桥**：9 孔钢桁梁，公路在桁架顶上、铁路在桁架里面（下层有钢轨和一列绿皮车），腹杆是交叉斜杆加竖杆。
  桁高和两片主桁的间距比真桥的比例大：照真比例，从沙盘的俯视角度看，桁架几乎全被挑出的桥面挡住。
  漆色用铁灰，浅灰会和江水混成一片。
- **桥墩**：8 个，下段带分水尖、略有收分，上面是墩身、墩帽和支座，水线处一圈水渍。
- **桥头堡**：两岸各一对方塔夹着桥面，开竖条窗，塔顶是重檐四角攒尖的亭子；两塔之间是桥台，临江一面是铁路的门洞
  （铁路引线没有做，火车从门洞进出）。
- **引桥**：连拱高架缓缓落地，离地不够起拱的一段是实心挡墙；滨江路和山径从拱下穿过。落地后接一条大道，
  东岸通到高楼街区，西岸翻过龟山脚到沙盘边。
- **桥面**：沥青路面、标线、人行道、边梁和栏杆、灯柱，四条车道上有随机摆放的小汽车和公交车。

桥的轴线是全局的 `BRIDGE_P0` / `BRIDGE_P1`，桥头堡的位置由 `bridge_layout()` 沿轴线找水边算出。

改桥时不打乱别处的做法：`keep()` 登记的避让范围沿用旧桥的，一处不改；新增的避让写在 `no_plant()` 里
（`plant()` 遇到这些地方照常消耗随机数，只是不种）；压在引桥下面的街区用 `MUTE` 开关照常走一遍但不出几何。
这样别处的树和房子一棵一栋都不变，新旧成图可以逐像素对比，确认只动了桥和江。

**江水**（材质 `RiverWater`）是浑浊的黄绿色，几乎不透明：泥沙多的江水看不到江底，原来透射 0.55，船影会穿到江底，
像玻璃盖着沙滩。水色有顺流方向的泥沙条带，近岸偏黄（江面网格的逐顶点属性 `depth` = 离岸多远）。
货驳和游轮后面有尾迹和八字波，桥墩下游有水纹（`wakes()`，材质 `Foam` 按 UV 淡出；只在成图里，网页版不导出）。

**岸线**：江底和岸坡两种材质的分界是沿地形网格走的锯齿，所以放在水面以下；水线以上的湿泥护坡由 `Terrain` 材质
按高度渐变画出来（网页版写进顶点色）。
