# 杭州西湖微缩立体景观（West Lake diorama）

独立于主项目（地球编年史 / Earth Chronicle）和故宫沙盘的子项目：用 Blender 5.x 过程化生成
一座 45° 俯视的西湖微缩模型，Cycles 渲染成图。

内容：悬浮地层岛屿上的湖泊高度场（湖床随离岸距离变深）、透射湖水与多层波纹、
苏堤六桥与白堤（锦带桥、断桥）、西泠桥、孤山（楼外楼、平湖秋月、西泠印社）、
小瀛洲（三潭印月、九曲桥）、湖心亭、阮公墩、雷峰塔（夕照山）、保俶塔（宝石山）、
净慈寺（黄墙）、岳王庙（红墙）、曲院风荷荷叶、集贤亭、柳浪闻莺、湖滨步道与城里的粉墙黛瓦、
画舫与小船（带尾迹）、沿湖石砌驳岸与岸边芦苇、堤岸桃柳相间、层叠秋色群山上的实例化针叶林，
以及贴水薄雾、西岸山脚与北岸的分层烟波和远景空气透视。
湖水不是“带凹凸的漫反射面”，而是两层：水体散射色（平法线的漫反射，不随波纹明暗，仍接收投影；湖心深、岸边浅）
加菲涅耳加权的镜面倒影（天空、山、树、亭、船），波纹只扰动倒影；沿风向拉长的条带风痕决定哪里平静如镜、
哪里被吹皱；近岸水浅处略透出湖床。天空对镜面反射光线单独调亮（`--skygloss`），反射权重可用 `--refl0/--refl1` 调。
水面网格带 `shore` 顶点属性（R = 离岸 2.6 单位内的岸线系数，G = 14 单位内的深浅系数）。
环湖公园带：北山路/南山路方向的环湖道路与湖滨路（遇建筑外移）、路上车辆、行道树、沿路花坛、
几处广场与通向湖边的小径，草地带大尺度斑驳；湖滨老城为错位街区，房屋在墙面/屋顶/层数/朝向上各有变化，
离湖远的街区混入平顶楼房，少量街区是小公园或公共建筑。晨光：太阳仰角 24°、偏暖，贴水雾气向光散射。
山林按斑块噪波留出林窗与草坡、高处稀疏、南坡阔叶北坡松林、秋色成片，林窗里有山岩堆，西山与南屏山各有
一条上山小径和山顶亭；湖面向阳（东北）一侧有细碎光斑（水面材质里按太阳方位做的发光闪点，`--noglitter` 关闭）；
湖滨、北里湖、花港各有码头与成排停靠的游船，湖滨和苏堤附近散落手划船。
树木与灌木是 Poly Haven 的扫描模型（叶片材质在脚本里重建并染色），天光与倒影来自 HDRI。

## 运行

在仓库根目录执行：

```bash
npm run blender:westlake
```

快速预览（40% 分辨率，16 spp）：

```bash
npm run blender:westlake:preview
```

直接调用脚本可用的参数：`--pct`、`--samples`、`--out`、`--save`、`--nomist`（关闭雾）、`--nohdri`、
`--sunonly`、`--border x0 y0 x1 y1`（裁剪渲染，用于 100% 检查局部）；调试开关 `--noshore`（关闭浅水带/白沫）、
`--nonewmist`（只保留贴水薄雾）、`--shorediag`（把 shore 属性显示为发光）。

坐标：1 个 Blender 单位 ≈ 25 米，y 轴正方向为北，湖面 z = 0。

## 网页版湖面

网页版（`src/diorama/LakeSurface.js`）按成图的湖水原理做了实时版本，不再用 three.js 自带的 Water.js：

- 水体色：不随波纹明暗的散射色，读水面网格的 `shore` 顶点色（R 近岸、G 水深）做深浅渐变，只接收阳光阴影；
- 镜面倒影：平面反射画山、树、建筑和船（背景留空），天空按反射方向查 HDRI 并对齐太阳方位，波纹只扰动倒影；
- 条带风痕：沿风向拉长的噪波决定平静与吹皱，驱动波纹强度、倒影模糊和闪点，并随时间缓慢漂移；
- 闪点大小按屏幕像素自适应；近岸半透明透出湖床，岸线有白沫；
- 各画质档的倒影里都画树（倒影贴图分辨率随档位 1024 / 512 / 256）。

可调参数都是材质 uniform（`skyGain`、`skyMax`、`reflRange`、`ripple`、`distortion`、`glitter`、`ambient`、`sunGain` 等），
浏览器控制台里用 `__diorama.scene.children.find(o => o.isLakeSurface).material.uniforms` 实时试。
