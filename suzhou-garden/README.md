# 苏州园林 · 微缩沙盘

用 Blender 过程化生成的苏州古典园林微缩模型：45° 俯视，白墙黛瓦，池居中，地形边缘是沙盘切面，悬浮在浅色背景上。
成品图在 `output/suzhou_garden/suzhou_garden.png`，可旋转的网页版在 `/earth-chronicle/dioramas/suzhou-garden/`。

```bash
npm run blender:suzhou            # 全分辨率成图（2048×1792，64 采样）
npm run blender:suzhou:preview    # 半分辨率整幅预览（约 2 分钟）
npm run blender:suzhou:web        # 导出网页版 → public/dioramas/suzhou-garden/
```

局部检查用 `--border x0 y0 x1 y1`（画面比例，原点在左下），例如
`blender --background --python suzhou-garden/build_suzhou_garden.py -- --samples 24 --border 0.30 0.38 0.66 0.70 --out crop.png`。

## 布局

单位：1 个 Blender 单位 = 1 米，y 轴向北，水面 z = 0，庭院地面 z = 0.45。以网师园为蓝本：

- **池**居中（`pond_sd()` 给出到池岸的带符号距离），西北有水湾，小石拱桥跨过；东南也有一处水湾。
- **北岸**：四面厅与临水月台。**西北**：两层的楼。**西岸**：曲廊与半架水上的六角亭。
- **西南**：太湖石大假山，山顶立方亭。**南岸**：架在水上的水阁；南院是花街铺地、黄石和红枫，故意留低，不挡池面。
- **东岸**：曲桥、方亭、沿界墙的廊。**东北**：书斋小院，南墙开月洞门。
- **东侧住宅**：门厅、大厅、后楼三进，中间是天井和带月洞门的庭院。
- **园外**：南面是临河的街巷，河道东西向贯穿沙盘（石驳岸、河埠头、石拱桥、乌篷船，两岸垂柳），在沙盘边缘切出缺口；
  北面墙外是一排邻家的粉墙黛瓦民居，只作背景。
- 相机在东南，所以有门窗细节的立面都朝南或朝东；高的建筑放在北面和西面。

## 做法

- **屋顶**（`suzhou_roof` / `pav_roof`）：歇山、硬山、攒尖三种。屋面按举折曲线起坡，翼角起翘并外翘，檐角伸出上挑的尖角；
  筒瓦垄、正脊、戗脊、垂脊都是真几何，底瓦用贴图。
- **墙**（`garden_wall`）：粉墙加墙帽，可开漏窗（四种花格）、月洞门、门洞；`wave` 参数做墙顶起伏的云墙。
  粉墙材质带檐下雨痕和墙脚返潮的青色。
- **太湖石**（`make_rock`）：融球体。正球竖向堆叠成形，负球挖出孔洞，再沿法线按噪声起皱；凹处按曲率压暗，顶面生苔。
  黄石同法但不挖洞，并把顶点吸附到粗格点上做出块面。
- **池水**：与西湖同一原理。水体色（不随波纹明暗）之上叠加镜面倒影，波纹只扰动倒影；水色碧绿，近水面略透，看得见锦鲤和荷梗。
- **植物**：园外的大树和少量野生灌木用 Poly Haven 扫描模型；造型松（盘曲树干加层层云片）、修剪成球的灌木和杜鹃、
  竹丛、芭蕉、荷、沿阶草是过程化网格。园内不用冷杉模型充当松树，树形不对。
- **光**：下午的侧光，太阳在西偏南、仰角 38°。相机在东南，光从侧面来，影子才会横过院落；正面光会把整张图压平。

## 踩过的坑

- 两个完全重合的面会互相遮挡阳光，渲染成纯黑的一块。出现过三次：重复的石板、转角处重复的望柱和廊柱、
  小径交汇处同高相叠的石板。现在石板高度带随机差，铺地逐块抬高 2 毫米，转角柱只放一根。
  出图后用 `python tools/black_scan.py <成图>` 扫一遍，再人工看标出的位置。
- 苔地不能调得太亮，一亮就成了草坪。地面的层次靠修剪灌木、沿阶草和铺地来给。
- 倒角着色节点很耗时，屋面和墙面这样的大面积材质不要开。
- 月洞门是题眼，门前（朝相机一侧）不能种树种竹；按相机方位检查视线。
- 网页版里山石、竹、芭蕉只导出一份模型，位置写在 `scene.json` 的 `instances` 里；山石的尺寸取精细网格的，保证网页和成图布局一致。
