# 苏州园林 · 微缩沙盘

用 Blender 过程化生成的苏州古典园林微缩模型：45° 俯视，白墙黛瓦，池居中，地形边缘是沙盘切面，悬浮在浅色背景上。
成品图在 `output/suzhou_garden/suzhou_garden.png`，可旋转的网页版在 `/earth-chronicle/dioramas/suzhou-garden/`。

```bash
npm run blender:suzhou            # 全分辨率成图（2048×1792，64 采样）
npm run blender:suzhou:preview    # 半分辨率整幅预览（约 2 分钟）
npm run blender:suzhou:web        # 导出网页版 → public/dioramas/suzhou-garden/
```

局部检查用 `--border x0 y0 x1 y1`（画面比例，原点在左下），例如
`blender --background --python suzhou-garden/build_suzhou_garden.py -- --samples 24 --border 0.30 0.38 0.66 0.70 --out crop.png`。

## 布局

单位：1 个 Blender 单位 = 1 米，y 轴向北，水面 z = 0，庭院地面 z = 0.45。以网师园为蓝本：

- **池**居中（`pond_sd()` 给出到池岸的带符号距离），西北有水湾，小石拱桥跨过；东南也有一处水湾。
- **北岸**：四面厅与临水月台。**西北**：两层的楼。**西岸**：曲廊与半架水上的六角亭。
- **西南**：太湖石大假山，山顶立方亭。**南岸**：架在水上的水阁；南院是花街铺地、黄石和红枫，故意留低，不挡池面。
- **东岸**：曲桥、方亭、沿界墙的廊。**东北**：书斋小院，南墙开月洞门。
- **东侧住宅**：门厅、大厅、后楼三进，中间是天井和带月洞门的庭院。
- **园外**：南面是临河的街巷，河道东西向贯穿沙盘（石驳岸、河埠头、石拱桥、乌篷船，两岸垂柳），在沙盘边缘切出缺口；
  河对岸有沿河小巷，东西两头各有一组临河民居，中间留空（近处的房子会挡住身后的河道，所以不排满）；
  临河民居是近景：有的山墙做成马头墙，有的楼层是木板壁通排花窗；朝镜头的一面开门、加瓦顶门罩，
  窗有石窗台和木窗板，屋前放水缸、柴垛、石凳、盆栽和晾衣竿。
  北面墙外的邻家是正屋夹厢房：正屋顺着园墙，两座厢房垂直于园墙、山墙朝南，高低进深各不相同。
  东面墙外是一条巷弄（见下面的"东墙外的巷弄"）：南头接河边的街巷，北头在东北角被沙盘边切断、拐向北面邻家。
- 粉墙做旧：雨痕从瓦帽、屋檐、窗台下往下挂，长短不齐；墙脚一道高低不齐的青灰返潮带。
  做法是让网格构建器给每个粉墙顶点写入所在墙段的顶高（属性 `topz`），材质用 `topz − z` 得到离墙顶的距离。
  强度用 `--rain`（默认 2.2）和 `--damp`（默认 1.8）调。驳岸、河埠头、池岸的石材在水线以上发暗生青苔。
  网页版也有同样的做旧：导出时把每个粉墙顶点离墙顶的距离写进顶点色（R = 距离 / 8 米），
  查看器给粉墙材质加一段着色代码（`src/diorama/Viewer.js` 的 `weatherPatch`），强度在 `scene.json` 的
  `mat.FenQiang.weather`（`rain`、`damp`、`ground`）里调；石材的青苔是 `mat.<材质名>.wet`。
- 相机在东南，所以有门窗细节的立面都朝南或朝东；高的建筑放在北面和西面。

## 做法

- **屋顶**（`suzhou_roof` / `pav_roof`）：歇山、硬山、攒尖三种。屋面按举折曲线起坡，翼角起翘并外翘，檐角伸出上挑的尖角；
  筒瓦垄、正脊、戗脊、垂脊都是真几何，底瓦用贴图。
- **墙**（`garden_wall`）：粉墙加墙帽，可开漏窗（四种花格）、月洞门、门洞；`wave` 参数做墙顶起伏的云墙。
  粉墙材质带檐下雨痕和墙脚返潮的青色。
- **太湖石**（`make_rock`）：融球体。正球竖向堆叠成形，负球挖出孔洞，再沿法线按噪声起皱；凹处按曲率压暗，顶面生苔。
  黄石同法但不挖洞，并把顶点吸附到粗格点上做出块面。
- **池水**：与西湖同一原理。水体色（不随波纹明暗）之上叠加镜面倒影，波纹只扰动倒影；水色碧绿，近水面略透，看得见锦鲤和荷梗。
- **植物**：园外的大树和少量野生灌木用 Poly Haven 扫描模型；造型松（盘曲树干加层层云片）、修剪成球的灌木和杜鹃、
  竹丛、芭蕉、荷、沿阶草是过程化网格。园内不用冷杉模型充当松树，树形不对。
- **光**：下午的侧光，太阳在西偏南、仰角 38°。相机在东南，光从侧面来，影子才会横过院落；正面光会把整张图压平。

- **水色**：池水和河水分开。河道的顶点在 `shore` 属性的 B 通道记 1，材质按它把水体换成浑一些的灰绿色、近岸不透。
  倒影的强度和色调压过一次（`--refl0` 0.36 → 0.22，`--skygloss` 0.42 → 0.30，`--wgloss` 倒影色调偏绿）：
  原来四成的水面在反射蓝天，池水和河水都是泳池一样的蓝青色。`--wcanal 0` 可以让河水回到和池水一样。
  网页版也分开了：水面顶点色的 B 通道就是河道标记，`src/diorama/LakeSurface.js` 按它换成 `scene.json` 里
  `lake.canalDeep / canalNear / canalShore` 这一组颜色（`lake.canalMix` 是开关，别的场景默认 0），近岸也不透。
  网页的河水色比成图材质里的深一档：网页上天光倒影更亮，照搬成图的数值会发白。
- **生活气息**（`street_life()`）：沿河的石板路原来是空的。加了四个摊位（木桌、竹筐里的菜和果子、竹竿撑的布棚、红灯笼）、
  柳树下的茶桌、河边的路灯、板车、自行车，和二十来个小人（`figure()`：站、走、坐、蹲四种姿势，可戴斗笠、撑油纸伞、穿长衫）：
  摊主和买菜的、喝茶的、拉车的、河埠头洗衣的、船尾的船夫、撑伞过桥的、园里曲桥上和赏石的游客。
  小人不做五官，按沙盘人偶的样子做。用自己的随机数状态，放在所有布置之后，别处不受影响。
  穿长衫的小人原来放大看是一根直筒，现在下摆撒开、腰里收住、系一条腰带（深衣配浅带，浅衣配深带），
  袖子上窄下宽、袖口露出手，下摆前露出鞋尖；位置、人数、衣服颜色都没动。
- **东墙外的巷弄**（`east_lane()`）：园墙到沙盘边只有 5.7 米（外墙皮 x = 34.14，沙盘边 x ≈ 39.9；北头收窄，到墙角只剩 2.5 米），
  原来是一条空草带，立着几棵带石座的树。现在贴着园墙是一条 2.3 米宽的石板巷：墙脚一道明沟，巷心一路长短不一的长条石。
  巷子东侧从南到北：巷口的挡车石、路灯、墙脚花池里的芭蕉、树池和石凳；一座马头墙民居（窗朝东）；它的小院（院门、晾衣竿、水缸、柴垛）；
  井台小场地（园墙上一道带瓦顶门罩的边门，对面一口公井、一棵树、石凳、自行车、盆栽）；一高一低两座民居；竹丛花池；一小块搭了豆架的菜畦。
  添了六个小人：巷口歇脚说话的两位、井边洗衣的、沿巷走的长衫先生、菜地里蹲着的、北头撑伞的。
  原来种在这条带子上的 41 棵树、灌木、竹丛用 `clear_plants()` 事后拿掉（成图删物体，网页版删实例记录），不是事先避让：
  避让会改变随机数的消耗，园里的布置就全挪位了。新东西都在 `EastLane` 一个网格和三座 `EastHouse` 里。

## 踩过的坑

- 两个完全重合的面会互相遮挡阳光，渲染成纯黑的一块。出现过三次：重复的石板、转角处重复的望柱和廊柱、
  小径交汇处同高相叠的石板。现在石板高度带随机差，铺地逐块抬高 2 毫米，转角柱只放一根。
  出图后用 `python tools/black_scan.py <成图>` 扫一遍，再人工看标出的位置。
- 苔地不能调得太亮，一亮就成了草坪。地面的层次靠修剪灌木、沿阶草和铺地来给。
- 倒角着色节点很耗时，屋面和墙面这样的大面积材质不要开。
- 月洞门是题眼，门前（朝相机一侧）不能种树种竹；按相机方位检查视线。
- 网页版里山石、竹、芭蕉只导出一份模型，位置写在 `scene.json` 的 `instances` 里；山石的尺寸取精细网格的，保证网页和成图布局一致。
- 东边缘上的东西站在相机和园子之间。相机方位 34°，往东西方向看过去，视线的坡度是 tan 40° ÷ sin 34° ≈ 1.5：
  檐口高 3 米的房子只挡住它西边 2 米的地面，所以巷东的房子只做一层，被挡住的只有巷子本身，墙里的住宅、庭院都还在；
  两层的就会吃进园墙里面，不要放。
- 高的东西在画面里是往"上"（北偏西）投的：石凳放在树的北面、菜畦放在竹丛的北面，都会被树冠整个盖住。
  要露出来的矮东西放在高东西的南面或东面，摆之前先算一下。
- 东墙外整条带子下午都在园墙和住宅的影子里。深色的土放在背阴的苔地上完全看不出来（菜畦第一版就是这样），
  背阴处要靠明度差：浅色的干土、浅灰的石头、白墙。
- 改完以后怎么确认园里没动：不渲染，把所有物体的位置、旋转、缩放和网格顶点的哈希导出来，和改之前的逐个比。
  注意 Blender 会把删掉的物体名字让给后来新建的物体，按名字比会显示"变了"，其实是旧的删了、新的顶了名字。
