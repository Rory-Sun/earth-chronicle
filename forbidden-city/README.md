# 故宫微缩沙盘（Forbidden City diorama）

独立于主项目（地球编年史 / Earth Chronicle）的子项目：用 Blender 5.x 过程化生成一座
45° 俯视的故宫微缩模型（悬浮地层岛屿、琉璃瓦、朱墙、汉白玉台基、景山、筒子河），
Cycles 渲染成图。

## 目录

| 路径 | 内容 |
|---|---|
| `build_forbidden_city.py` | 唯一的脚本：建模、材质、灯光、相机、渲染 |
| `../assets/textures_cc0/` | ambientCG 的 CC0 贴图，各沙盘共用（来源见其中 `README.md`，`_dl/` 下载缓存不入库） |
| `output/forbidden_city/forbidden_city.png` | 正式成图（2048×1792，128 spp） |
| `output/forbidden_city/forbidden_city.blend` | 工程文件（不入库） |

## 运行

在仓库根目录执行：

```bash
npm run blender:palace
```

快速预览（40% 分辨率，16 spp）：

```bash
npm run blender:palace:preview
```

直接调用脚本可用的参数：`--pct`、`--samples`、`--out`、`--save`、
`--sunonly`、`--nosun`、`--border x0 y0 x1 y1`（裁剪渲染，用于 100% 检查局部）。

CPU 渲染一张正式图约 15–17 分钟。出图后跑一遍 `python tools/black_scan.py <成图>`，再人工看标出的位置。

## 做法和踩过的坑

- **重合面发黑**：两个面完全重合时互相遮光，渲染成纯黑的方块。这张图里出过四种：
  宫墙在转角相叠、两个院子共用同一道墙（`wall()`）；三台的三块台面互相多伸出一截；后三宫的十字形月台；
  成排的廊庑首尾相接、屋面落在同一个斜面上（`corridor()`）。
  现在每段墙、每座廊庑的厚度和高度按序号各差几毫米，台面改成首尾相接、互不相叠。差值不取随机数，树木位置不变。
- **取景**（`fit_camera()`）：方位和俯角不变，自动平移视线落点、调整距离，让整个沙盘（含切面的尖底和树梢）
  落在画面里并居中。原来落点和距离是手调的，沙盘左侧和底部伸出了画面。`--nofit` 用回手调的值。
- **水**（`water()`）：筒子河和内金水河是单独的水面网格，带顶点属性 `shore`（R = 近岸程度，G = 水深程度）。
  材质和苏州园林的池水同一做法：水体色用平法线的漫反射（不随波纹明暗，仍接收投影），上面叠加菲涅耳加权的镜面倒影，
  近岸略透出河床。原来是一个青色的光滑平面，像泳池。颜色用 `--wnear`、`--wdeep`、`--wshore`、`--wrefl` 调。
- **铺地**：石板贴图的比例从 0.7 调到 1.5（`--pave`），原来一块石板在图上有六米见方，把整座城衬成了玩具；
  贴图里相邻石板色差很大，缩小后是一片跳动的格子，所以先往平均灰色上收一半（`--paveflat`），再乘几十米一片的深浅。
- **屋顶**：每座屋顶的明暗略有不同（几何节点的 Random Per Island，`--roofvar`），顺坡加雨水冲出的暗痕（`--roofstreak`）。
  红墙有竖向雨痕，墙脚返潮发暗。
- **游人和陈设**（`court_life()`）：中轴线上五百多个小人（一段身子一个头，三成戴帽子），成群地站在午门外、
  太和门广场、金水桥上、太和殿广场、三台和后三宫台基、御花园；太和门前一对铜狮，太和殿前的铜鼎，台基脚下的铜缸。
  小人比真实比例大一倍（建筑本身也放大了 1.8 倍），否则在图上不到两个像素。用自己的随机数。
- 东华门、西华门外加了石桥；筒子河外岸加了一排垂柳（放在所有种植之后，原有树木不动）。
- 景深的光圈从 f/1.0 收到 f/1.6（`--fstop`）：原来近处和远处的屋顶糊成一片，看着像低分辨率。
- **网页版**：筒子河用 `src/diorama/LakeSurface.js`（和西湖、苏州园林同一个水面），参数在 `scene.json` 的 `lake` 里。
  这个水面是一个平面镜，只能有一个水位，所以内金水河在导出时单独成一个普通的光滑材质。
