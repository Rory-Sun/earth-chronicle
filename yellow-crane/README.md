# 武汉黄鹤楼微缩立体模型（Yellow Crane Tower diorama）

第三座沙盘子项目，与故宫、西湖同一套管线（`west-lake/` 的脚本派生）：Blender 5.x 过程化生成，Cycles 渲染成图，
并以 `--export-glb` 导出 Three.js 网页版（`dioramas/yellow-crane/`）。

内容：蛇山台地上的黄鹤楼（三层石台、五层平座朱栏、每面三翘角的黄色琉璃瓦飞檐、攒尖宝顶）、
公园的牌坊、碑廊、亭台、白云阁、鹅池与山径，斜贯沙盘的长江与江滩滨江路，武汉长江大桥（见下），
对岸龟山、电视塔与晴川阁，两岸粉墙黛瓦的老城，江上货驳、游轮与小船（带尾迹），
Poly Haven 扫描树木实例化的松林与垂柳，日落纯天空 HDRI 的金色低角度阳光与贴水薄雾。

## 运行

```bash
npm run blender:crane            # 正式渲染（约 20 分钟）
npm run blender:crane:preview    # 快速预览（40%，16 spp）
npm run blender:crane:web        # 导出网页版 glb + scene.json
```

直接调用脚本的参数：`--pct`、`--samples`、`--out`、`--save`、`--nomist`、`--nohdri`、`--sunonly`、
`--border x0 y0 x1 y1`、`--export-glb <dir>`、`--foam`（船尾迹的浓度，默认 0.8）。
坐标：1 个 Blender 单位 ≈ 12 米，y 轴正方向为北，江面 z = 0。

## 黄鹤楼脚下的石矶和台地

楼的基座立在 `ground(楼心)` = 12.7 的高度，而原来周围的台地只有 9.6，西北角下面干脆是江面：石台整个悬空，
牌坊、碑廊、亭子不是悬空就是埋在石台里。现在把这座山补实成一座临江的石矶（黄鹄矶）：

- **山体**（`terrain_geo()`）：山顶是放石台的平地，四周是很陡的岩壁，崖脚一圈乱石滩伸进水里；
  东面接蛇山的地方比广场高，削成坡。陡面用岩石材质 `HillRock`（Rock051 贴图，朝上的面生苔）。
- **砌体**（`tower_hill()`）：山顶广场四周的条石挡墙和栏杆；南面两层石砌台地，三层之字形台阶从广场下到前场；
  台地上是牌坊和两座碑廊，广场四角各一座亭子，前场还有一道牌坊。山径从前场出发，穿过大桥引桥的拱洞进老城。
- **树**：崖脚一圈的树、岩缝里的灌木和小松、东坡的松林、台地上的点景树，都由 `tower_hill()` 自己摆；
  白云阁周围原来秃着的一圈也补上了。

只改地形网格的高度，`terrain()` / `ground()` 一个字不动：种树、建房的判断都用它们，判断不变，随机数的消耗就不变，
别处的树和房子不会跟着变。摆放高度一律用 `surface()`。原来摆在这一带的建筑在旧位置照原样走一遍（只登记避让范围，
几何丢掉），新的摆完以后把它们自己登记的避让范围删掉。

## 现代城区

`city()` 铺街区，`tower_block()` 盖高楼。原来的楼是白底横条的方盒子，立在一块空铺地上，同一街区里的楼还会互相穿插。

- **高楼三种做法**：玻璃幕墙写字楼（楼板线、竖梃，高的顶上有收进的机房层和天线）、住宅板楼（窗带被窗间墙分成一格格的窗，
  朝南挂阳台，屋顶有水箱）、竖向窗带的塔楼（顶上两层收进）。多数带裙楼，屋顶有女儿墙和设备间。
- **街区**：除了高楼，还有几栋沿街的三到七层的多层楼、一两块带树的绿地、沿地块四边的行道树，街上有车和黄色中线。
  坡地上的街区下面垫石砌护坡（原来是一块悬空的板）。
- 重叠的高楼挪到旁边的空处，挪不开就不建。

高楼的位置、大小、层数仍按原来的顺序抽全局随机数，其余的变化都用按街区定种子的随机数，别处的树和房子不变。

## 老城和补出来的新街区

- **民居**（`_house()`）：一排联排的老房子，硬山瓦顶，两端和几户之间立三级叠落的马头墙，正面一条木门板，背面和楼上开窗；
  墙面有粉墙、青砖、红砖三种。原来每栋都是一样的白盒子加四坡顶。
- **老城街区**（`town_block()`）：沿街两排民居，院里一到三座厢房把前后两排连成几进院子，院里种树，街区两头是院墙和门楼。
- **补新街区**（`grow_quarters()`）：原来两岸大片平地是空草地。现在从已有的街区出发往外补：
  老城旁边长出老城街区，现代城区旁边长出多层住宅小区（`xiaoqu_block()`：三排朝南的板楼，排间绿地，偶尔换成一块街心公园）。
  第一轮贴着已有街区按原来的间距往四个方向长；第二轮见缝插针，补网格对不上的空地。
  只落在平坦、离江和岛缘够远、不压已有建筑、大桥、石矶和山径的地方。

新街区不登记 `keep()`（那会改动后面种树的随机数），范围记在 `NEW_ZONES` 里由 `no_plant()` 挡树；压在下面的已有的树拿掉
（`PLANT_REG` 记着每棵树）。老城原有街区的随机数抽取顺序没变，其余变化用按街区、按房子定种子的随机数。

## 路网和地块

原来每个街区是单独摆在草坪上的一块垫子，互相不连；街区之间和沿江的平地是空草地。现在分两步填：

- **规划**（`urban_plan()`，纯计算）：把沙盘划成 2 × 2 的格子，挑出能用的格子（平坦的干地，不压街区、建筑、大桥、石矶、山径）。
  街区垫板挨着的算一片；先用最短路把各片连成树（已有的路几乎不要钱，拐弯和贴着别的路并排走要加钱），
  再在挨得近却要绕远的两片之间补几条成环，最后接几处滨江路。然后沿街摆地块：学校、广场、球场、停车场、商铺必须临街
  （挨着路或挨着街区，街区垫板的外沿就是街道），公园和苗圃不必。
- **几何**（`urban_fill()`）：
  - **路**：一格一块路面，高度取格子四角的地面再抬 0.08，相邻的格子共用角点，所以是连着的一张面。
    人行道、车行道是同一张面上不同材质的小格，互不重叠；拐弯的内角补一小块人行道；直路中间一条黄线。
    路的端头接到街区垫板上；路边离街区不到一格的缝铺成人行道。接滨江路的一段一直铺到滨江路的中线。
  - **地块**：学校（红色跑道围着草地的操场、两排教学楼、门房、球场）、球场、停车场、喷泉广场、沿街商铺、
    公园（池塘、绕池石径、亭子、成片的树；不垫板，就在草地上）、苗圃（成垄的小树）。
  - **树**：路边的空地上种行道树；剩下的空地种成一丛一丛的树，丛与丛之间留出草地，江边多垂柳。

全部用自己的随机数状态；占地用 `claim()` 记进 `NEW_ZONES`，不登记 `keep()`，所以山林、街区、江面都不变。
成图和网页版的街区数不一样（33 和 34 个），路网和地块是各自规划出来的，细节不同。

## 光线

西南方向的低角度夕照：太阳仰角 20°、强度 4.6、颜色 (1.0, 0.83, 0.60)，HDRI 天空 0.26，一盏冷色的面光做补光（210）。
调光用的参数都能从命令行覆盖：`--sun-el`、`--sun-energy`、`--sun-col r,g,b`、`--sky`、`--fill`、`--fill-col r,g,b`、
`--exposure`、`--grass r,g,b`（草地颜色的倍数）。

原来是仰角 25°、强度 3.8、颜色 (1.0, 0.87, 0.68)、天空 0.3、补光 250：明亮干净，但暖色和长影子都不明显。试过两个方向，都不如原来：

- 把环境光压到 0.16 ~ 0.22、补光减半：阴影成了灰褐色，整张图发闷。
- 加强太阳再降曝光：自发光的背景板跟着变灰。

定下来的是小幅调整：太阳低一点、强一点、暖一点，天光和补光各减一成多，草色略压。受光的立面更暖，影子长了约三成，
过曝像素的比例和原来一样（约 2.3%），江水的色相基本不变。网页版的太阳方向、颜色和强度跟着这几个参数走。

## 山林的边界

山林是按“地面高过 1.2 就种”撒的，边界就是一条等高线，齐得像修剪过的绿篱。`feather_forest()` 在所有种植之后改：

- **往里疏**：山脚临平地的林缘，往里三格（一格 1.8）以内疏掉一部分树，越靠外疏得越多。
  只从山脚的平地量起，坡上的林间空地（亭台周围、山径两侧）不算：否则坡上被疏出一块块光秃的山坡。
- **往外散**：林缘往外四格以内零星补树，越远越稀、越小，阔叶树和秋色树多一些。
- 一张低频噪声决定哪一段往里凹（疏得多、不往外补）、哪一段往外伸（疏得少、补得远），边界才是犬牙交错的。

贴着岛缘切面和江边的林子不动。用自己的随机数状态，放在最后，别处不受影响。

## 补充的真实景物

沙盘是写意的：几样标志物的方位关系对，比例和距离是压缩的，楼放在了临江的石矶上（现在的黄鹤楼其实离江约一公里，
古代的才在江边的黄鹄矶）。在不动布局的前提下，`landmarks()` 补了几样真实存在的内容：

- **胜像宝塔**：公园里元代的白色喇嘛塔，在南面台地的西翼。
- **黄鹤归来铜雕**：龟蛇背上两只黄鹤（一只昂首举翅，一只收翅平视），在台地的东翼。
  大小照沙盘里黄鹤楼的大小来定（真的铜雕高 5.1 米，约是楼高的十分之一），鹤的脖子、腿、喙比真鹤粗得多：
  照 1 单位 = 12 米和真实比例去做，在成图里只有十来个像素，脖子不到一个像素。
- **武汉长江大桥建成纪念碑**：武昌桥头江边的观景平台上。
- **孙中山铜像和首义广场一角**：红楼正门前。广场从门前铺到大道的人行道边，南沿和大道平行；
  铜像离开红楼的墙一段，它西北面（从成图的视角看是背后）到墙根铺白石板，深色的人像衬在上面才看得出来。
  人像也是夸大的（高约 1.6 个单位），基座做矮。
- **晴川饭店**：汉阳江边的白色高层。
- **轮渡**：两岸各一座趸船码头，江上两条渡轮（`ferry()`）。

没有做的：汉江汇入口和汉口、楼脚下的京广铁路（都要改布局），武昌江边的超高层（会抢主角）。

这些景物用 `claim()` 占地：范围记进 `NEW_ZONES`，已经种在那里的树拿掉；不登记 `keep()`。

## 长江大桥和江水

`yangtze_bridge()` 照 1957 年的武汉长江大桥来做：

- **正桥**：9 孔钢桁梁，公路在桁架顶上、铁路在桁架里面（下层有钢轨和一列绿皮车），腹杆是交叉斜杆加竖杆。
  桁高和两片主桁的间距比真桥的比例大：照真比例，从沙盘的俯视角度看，桁架几乎全被挑出的桥面挡住。
  漆色用铁灰，浅灰会和江水混成一片。
- **桥墩**：8 个，下段带分水尖、略有收分，上面是墩身、墩帽和支座，水线处一圈水渍。
- **桥头堡**：两岸各一对方塔夹着桥面，开竖条窗，塔顶是重檐四角攒尖的亭子；两塔之间是桥台，临江一面是铁路的门洞
  （铁路引线没有做，火车从门洞进出）。
- **引桥**：连拱高架缓缓落地，离地不够起拱的一段是实心挡墙；滨江路和山径从拱下穿过。落地后接一条大道，
  东岸通到高楼街区，西岸翻过龟山脚到沙盘边。
- **桥面**：沥青路面、标线、人行道、边梁和栏杆、灯柱，四条车道上有随机摆放的小汽车和公交车。

桥的轴线是全局的 `BRIDGE_P0` / `BRIDGE_P1`，桥头堡的位置由 `bridge_layout()` 沿轴线找水边算出。

改桥时不打乱别处的做法：`keep()` 登记的避让范围沿用旧桥的，一处不改；新增的避让写在 `no_plant()` 里
（`plant()` 遇到这些地方照常消耗随机数，只是不种）；压在引桥下面的街区用 `MUTE` 开关照常走一遍但不出几何。
这样别处的树和房子一棵一栋都不变，新旧成图可以逐像素对比，确认只动了桥和江。

**江水**（材质 `RiverWater`）是浑浊的黄绿色，不透明。水色有顺流方向的泥沙条带，近岸偏黄
（江面网格的逐顶点属性 `depth` = 离岸多远）。
水面的做法和西湖、苏州园林一样：水体色用平法线的漫反射（不随波纹明暗，仍接收桥和船的投影），上面叠加菲涅耳加权的
镜面倒影，波纹只扰动倒影；顺流方向拉长的风痕决定哪里平静如镜、哪里被吹皱。原来整个江面是带凹凸的 Principled：
波纹像刻在泥地上的浮雕，天空几乎映不出来，一整片均匀的土黄，像泥滩。
可调：`--rbody`（水体色的倍率）、`--rgloss`（倒影色调）、`--rrefl0` / `--rrefl1`（正视 / 掠视的倒影权重）。
货驳和游轮后面有尾迹和八字波，桥墩下游有水纹（`wakes()`，材质 `Foam` 按 UV 淡出；只在成图里，网页版不导出）。
尾迹不伸出沙盘；江口太靠外的船沿河道往里挪。
网页版的江面也换成了 `src/diorama/LakeSurface.js`（`scene.json` 带 `lake` 字段时生效），江面网格的顶点色 `shore`
给它近岸程度和水深。

**网页版的楼面**：`Facade`–`Facade4` 这几种面材底色很浅（0.5–0.86），成图是夕照、明暗面分明，网页的光照下整栋楼
冲成白色，远看城区是一片白方块。`scene.json` 的 `mat` 字段给它们各乘一个 0.5–0.6 的系数，玻璃再压一档、少映天空
（`mat` 现在也能覆盖查看器材质表里没有的材质）。老城的粉墙和水泥地没有动，南岸居民区仍偏浅。

## 取景和切面

- **取景**（`fit_camera()`）：方位和俯角不变，自动平移视线落点、调整距离，让整个沙盘（含切面的尖底和楼顶）落在画面里并居中。
  原来落点和距离是手调的，沙盘左、右、下三边都伸出了画面。`--nofit` 用回手调的值。
  沙盘完整入画以后露出两处原来被裁掉的毛病，一并修了：江口有一条船和尾迹伸到了沙盘外面；东北角一段老城的街悬出了边缘。
- **切面**（材质 `EarthCut`，`--cut 贴图比例,层厚,扭曲`）：岩石贴图的比例 0.14 → 0.26，分层波纹的扭曲 4.0 → 0.8、层厚减半。
  原来扭曲太大，在切面的每个折面上都成了人字形的折线，不像沉积层。

**岸线**：江底和岸坡两种材质的分界是沿地形网格走的锯齿，所以放在水面以下；水线以上的湿泥护坡由 `Terrain` 材质
按高度渐变画出来（网页版写进顶点色）。
